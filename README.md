# HSE Game

Игрок управляет персонажем на арене, отбивая волны врагов всё возрастающей сложности. Между волнами открывается магазин улучшений за собранную добычу. Игра заканчивается, когда здоровье персонажа падает до нуля.

## Управление

| Клавиша | Действие |
|---------|----------|
| WASD | Движение (8 направлений) |
| Space | Атака (удерживать для повтора) |
| Q | Переключить оружие (Меч / Дробовик) |
| Left Shift | Рывок (dash) с перезарядкой |
| E | Подобрать добычу |
| 1–3 | Купить улучшение в магазине |
| Enter | Закрыть магазин и начать волну |
| R | Перезапуск после Game Over |

## Механики

### Система волн

Каждая волна спавнит `3 + номер_волны × 2` врагов (максимум 20). Между волнами — 4-секундная пауза для передышки и покупок.

### Типы врагов

- **Преследователь** (красный) — бежит к игроку, наносит урон при контакте.
- **Стрелок** (фиолетовый) — держит дистанцию и стреляет снарядами.

### Система оружия

- **Меч** — ближний бой, прямоугольный хитбокс с поворотом по направлению, 25 урона, перезарядка 0.4 с.
- **Дробовик** — 5 дробин конусом (0.35 рад), 8 урона за дробину, перезарядка 0.9 с, отбрасывание ×2.4.

### Артефакты

- **Вампирский клык** — восстанавливает 1 HP за каждые 5 убийств.
- **Разрывные снаряды** — при убийстве врага создаёт AoE-взрыв (70 px, 20 урона).

Оба артефакта работают через шину событий (`EventBus`), что позволяет добавлять новые эффекты без изменения боевого кода.

### Магазин

Между волнами можно купить: макс. HP (+20), скорость (+30), урон атаки (+10), Вампирский клык, Разрывные снаряды. Цены растут с каждым уровнем: `базовая_цена + уровень × шаг_цены`.

### Визуальные эффекты

- Анимация спрайтов по тайлсету с автодетекцией прозрачных разделителей.
- Вспышка урона (цветовая модуляция на 0.18 с).
- Дуга удара мечом (TriangleFan, 120°).
- Следы за снарядами (затухающие круги).
- Тряска камеры с экспоненциальным затуханием.
- Плавное следование камеры за игроком.

## Архитектура

```
include/           # Заголовочные файлы
  combat/          # Оружие и артефакты
  core/            # Сущности, столкновения, события, магазин, волны
  entities/        # Игрок, враги, снаряды
  ui/              # HUD
src/               # Реализация
  combat/
  core/
  entities/
  ui/
  main.cpp         # Главный игровой цикл
tests/             # Модульные тесты (Catch2)
assets/            # Спрайт-атласы
```

### Ключевые решения

- **Entity** — абстрактный базовый класс с `update(dt)`, флагами жизненного цикла (`alive_`, `active_`, `visible_`) и AABB-коллизиями. Метод `draw()` — `final`, пропускает невидимые/мёртвые объекты, затем вызывает виртуальный `onDraw()`.
- **EventBus** — шина событий с type-erased подписками (`subscribe<Event>(handler)` / `emit<Event>(event)`). Связывает артефакты с боевой логикой без прямых зависимостей.
- **ResourceManager** — фабрика фигур SFML для фоллбэк-рендеринга, когда спрайты недоступны.
- **Физика с фиксированным шагом** — 60 Гц, переменный рендер. Столкновения со стенами разрешаются алгоритмом slide-along-walls (полное движение → только по X → только по Y → заблокировано).

## Сборка и запуск

Зависимости подтягиваются автоматически через CMake FetchContent. Нужны только компилятор C++23 и CMake 3.28+.

```sh
# Debug
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build
./build/bin/game

# Release
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
./build/bin/game
```

### Тесты

```sh
cmake -S . -B _build-tests -DCMAKE_BUILD_TYPE=Debug
cmake --build _build-tests
./_build-tests/bin/game_tests
```

### Чистая пересборка

```sh
rm -rf build cmake-build-*
```

## Структура ассетов

Каждая сущность хранит свои атласы в `assets/`:

```
assets/
  player/
    run.png     # Атлас анимации бега
    idle.png    # Атлас анимации ожидания
```

`Player` автоматически определяет прозрачные разделители в тайлсете для корректной нарезки кадров.
